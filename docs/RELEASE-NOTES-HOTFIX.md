## 🔧 إصلاحات 1.1.1 / 1.1.1 hotfix

🔔 إشعار التحديث الجديد: عند توفر إصدار أحدث يظهر إشعار بأبرز التغييرات مع زرّي «حدّث الآن» / «لاحقًا»، مرة واحدة فقط عند كل تشغيل، ويمكن إيقاف الفحص التلقائي من الإعدادات.
📦 نافذة «حول» تعرض الآن نوع النسخة (AppImage أو .deb أو .rpm أو Flatpak) مع مسار الملف التنفيذي؛ ونسخ .deb/.rpm تنزّل الحزمة المطابقة إلى مجلد التنزيلات بعد التحقق من بصمتها بدل إرسالك إلى صفحة الإصدار فقط.
🗂️ أصبح بالإمكان حذف التصنيفات الافتراضية (ما عدا «General»)، وحذفها كلها لم يعد يعيد إنشاءها عند التشغيل التالي.
🎵 قوائم التشغيل: خيار للترقيم من أقدم فيديو، وخيار لتخطّي الفيديوهات المنزّلة مسبقًا.
🎬 لوحة «نزّل هذا الفيديو» في المتصفح تحترم الآن إعداد إيقافها — لا تظهر بعد إيقافها، حتى في الصفحات المفتوحة أصلًا أو عندما يكون البرنامج مغلقًا.

Update notice: when a newer release is available, a notice shows its highlights with «Update now» / «Later», at most once per launch; automatic checks can be turned off in Settings. About now shows the running package kind (AppImage, .deb, .rpm, Flatpak) with the executable path, and .deb/.rpm installs download the matching verified package into Downloads instead of only pointing at the release page. Built-in categories can now be deleted (except General), and deleting all of them no longer re-seeds them on the next launch. Playlists: an option to number from the oldest video, and an option to skip videos already downloaded. The browser "Download this video" panel now honours its off setting — it stays hidden after being disabled, on already-open pages and when the app is closed.
